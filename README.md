# Integrated Matter Values

Shows Replication matter values on items in Integrated Terminals storage terminals.

Hover an item in a Storage Terminal and its matter values appear under the tooltip, the same pills the Replication terminal shows. Turn on Require Shift in the client config to only show them while Shift is held. Turn on Exact Values to show fractional values such as 0.25 instead of rounding them up; this applies to every Replication matter tooltip.

Client-side only: install it on your own game, servers do not need it.

NeoForge, Minecraft 1.21.1. Requires Integrated Terminals and Replication.
